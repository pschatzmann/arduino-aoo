Detailed Description

Audio source for AOO (Audio Over OSC) which is used to send audio data via the indicated output stream (usually a AOOStreamUDP). We provide a simple implementation which is purely based on the AudioTools library w/o any external dependencies. The call to write() will send the data to the output stream and process incoming messages (pings, resend and start requests, invitations). If you pause to call write(), make sure that you continue to call receive() to keep the ping alive.

By default we transmit PCM data, but you can also use any other encoder. If you decide to use a CopyEncoder to write already encoded data, you need to make sure that the writes are throttled by the decoded data rate, otherwise the sink will run into buffer overflows.

Blocks which do not fit into max_packet_size are split into several frames. The sent blocks are kept in a buffer (buffer_size blocks) to answer resend requests. The audio can be sent to several sinks (sink_targets); sinks can also add themselves with an invitation or a /start request.
