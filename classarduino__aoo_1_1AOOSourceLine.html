Detailed Description

The audio of one remote source (sender) received by an AOOReceiver.

The receiver creates one AOOSourceLine for each stream (identified by source id, sink id and stream id) and stores the received encoded segments with storeEncodedData(). The source line provides the decoded audio in the output format of the receiver: as an AudioStream it can be read directly or added to the InputMixer of the receiver.

It consists of

  • an IndexedRingBuffer of encoded segments (buffer_depth), which serves as jitter buffer: the audio is only provided once it is half full (priming)
  • the decoder and a FormatConverterStream, which converts to the output format and resamples for the adaptive resampling (updateDrift())
  • a QueueStream with the decoded audio
  • the packet recovery (resend requests) and the statistics

On read, the encoded segments are taken one by one from the buffer and written to the decoder, so that a decoder like Opus gets exactly one packet per write. A segment is only decoded when the queue has space for a complete decoded segment, so that the decoder never has to wait for free space. A missing segment is replaced by silence of the size of the last decoded segment.

◆ updateDrift()

void updateDrift ( AudioInfo output_info,
uint32_t update_ms,
float max_percent )
inline

Adaptive resampling: compensates the clock drift between source and sink by adjusting the playback rate so that the buffer stays half full. The rate deviates proportionally to the (smoothed) deviation of the fill level from the target, limited to max_percent. Called regularly; the rate is updated at most every update_ms.
