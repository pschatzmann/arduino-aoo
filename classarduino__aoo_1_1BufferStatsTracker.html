Detailed Description

Tracks statistics for an IndexedRingBuffer used as encoded data store. Call received() for each stored segment and updateStats() to recompute.

Member Function Documentation

◆ recentQualityPercent()

float recentQualityPercent ( ) const
inline

Quality of the recent past: received / expected within the current window of quality_window_ sequence numbers (or the previous window while the current one has fewer than min_quality_window_ entries). Unlike the cumulative quality, a loss early in the stream does not keep this value low for a long time.
