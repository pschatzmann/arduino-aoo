Detailed Description

Abstract transport stream for AOO (Audio Over OSC).

Provides a Stream interface with optional addressing (setRemote/remoteIP/ remotePort). Concrete subclasses implement the actual transport: UDP packets (AOOStreamUDP), HDLC-framed serial (AOOStreamSerial), or any other link that can carry AOO/OSC messages.
