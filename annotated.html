 CAOOSenderAudio source for AOO (Audio Over OSC) which is used to send audio data via the indicated output stream (usually a AOOStreamUDP). We provide a simple implementation which is purely based on the AudioTools library w/o any external dependencies. The call to write() will send the data to the output stream and process incoming messages (pings, resend and start requests, invitations). If you pause to call write(), make sure that you continue to call receive() to keep the ping alive
