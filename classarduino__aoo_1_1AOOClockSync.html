Detailed Description

NTP-style clock synchronization using AOO ping/pong round-trips.

Estimates the clock offset between source and sink from the three timestamps carried in every pong message (t1=source send, t2=sink receive, t3=sink send) plus the local receive time t4. All timestamps are NTP timetags (see aoo_ntp_now()), like in the official aoo library.

The offset is smoothed with an exponential moving average and can be queried to convert remote timestamps to local time.

This is used for latency monitoring only and not for the clock synchronization of the audio stream itself
