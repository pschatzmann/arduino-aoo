Detailed Description

Pull-based audio sink for AOO (Audio Over OSC).

Receives encoded audio data via the indicated transport stream, buffers it per source, and provides decoded/mixed PCM audio through the AudioStream readBytes() interface.

Each remote source gets its own encoded data buffer, decoder, format converter, and resampler. Decoded audio from all sources is mixed via InputMixer and pulled on demand through readBytes().
