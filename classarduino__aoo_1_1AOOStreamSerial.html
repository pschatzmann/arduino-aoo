Detailed Description

AOO transport over a serial link using HDLC framing.

Serial is a continuous byte stream with no inherent message boundaries. This class wraps an HDLCStream around the underlying serial port so that each write() is transmitted as a single HDLC frame (0x7E delimiters + byte-stuffing), and each read cycle returns exactly one complete frame. This gives the same one-write-per-message semantics that UDP provides natively, making it suitable for point-to-point AOO links over UART or USB-Serial.
