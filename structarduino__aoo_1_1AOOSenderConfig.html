◆ max_packet_size

int max_packet_size = 960

Maximum size of a /data message (UDP payload) in bytes: bigger blocks are split into several frames. Keep it below the network MTU minus 28 bytes for the IP and UDP headers, because many receivers (e.g. the ESP32-P4) drop IP fragments. The official aoo library uses 512.
